## Cómo citar este Dataset / How to cite

Si utilizas estos datos climáticos preprocesados y recortados para tus investigaciones, tesis o proyectos, por favor otorga el crédito correspondiente citando el dataset oficial de la siguiente manera:

> **López-Mora, D. A. (2026)**. Malla de datos diarios CHIRPS de 1981 a 2021 recortado para la zona de alta montaña en Veracruz, México. [Dataset]. Zenodo. https://doi.org/10.5281/zenodo.23539068
