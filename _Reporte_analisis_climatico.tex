\subsubsection{Objetivo general}\label{objetivo-general}

Analizar la representatividad de diferentes bases de datos climáticas
con diferentes resoluciones espaciales y temporales para el clima de
alta montaña en Veracruz

\subsubsection{Objetivos específicos}\label{objetivos-especuxedficos}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Identificar cuáles son las bases de datos que contienen información
  relevante para el sitio de estudio
\item
  Analizar el clima de la región utilizando datos de las estaciones
  climatológicas del Servicio Meteorológico Nacional
\item
  Evaluar la representatividad que tiene cada una de las bases de datos
  para el área de estudio
\end{enumerate}

\subsection{Preguntas de investigación e
hipótesis}\label{preguntas-de-investigaciuxf3n-e-hipuxf3tesis}

\begin{enumerate}
\def\labelenumi{\alph{enumi}.}
\item
  P: ¿Cuáles son las bases de datos que contienen información relevante
  para el clima de alta montaña en Veracruz? H: Las bases de datos que
  contienen mayor información relevante para el clima de alta montaña
  son las de corte regional y/o nacional, aunque varias de estas fuentes
  de información tienen errores.
\item
  P: ¿Cuál es la calidad de las bases de datos descargadas? H: Las bases
  de datos, especialmente las regionales y nacionales, tienen menor
  cálidad que las provenientes de fuentes internacionales. Sin embargo,
  estos ``huecos'' en la información pueden ser rellenados con métodos
  estadísticos.
\item
  P: ¿Qué nivel de representatividad tiene cada una de las bases de
  datos para el área de estudio? H: La mayor parte de las bases de datos
  tiene una buena representación del clima de la región de estudio. Esta
  información puede ser evaluada con técnicas/parámetros estadísticos.
\end{enumerate}

\subsection{Sobre la zona de estudio}\label{sobre-la-zona-de-estudio}

Se construyó un dominio con radio de 0.5°(\textasciitilde55.5 km.)
alrededor del Pico de Orizaba cuyas coordenadas son 19.03N, 97.26°O. De
lo anterior, el área de estudio quedó comprendida entre las coordenadas
{[}\ldots{]}.

Posterior a ello, se descargaron los datos del ECMWF Reanalysis v5 con
resolución temporal mensual y espacial de 0.25°(\textasciitilde27.75
km.) en el periodo comprendido de 1950 a 2025 para las variables
temperatura a dos metros y precipitación total. Por otro lado, los datos
que se utilizaron como referencia fueron los provenientes de la
climatología diaria del Servicio Meteorológico Nacional (SMN), los
cuales son datos puntuales para 106 estaciones cuya distribución
espacial se muestran a continuación:
